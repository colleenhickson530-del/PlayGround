# UNDERNEATH // 3120

**The sky is a memory. The city is yours.**

A playable 3D open-world survival city-builder set in the last underground city of 3120. Built with Vite and Three.js. All geometry, characters, vehicles, signs, portraits, and audio are generated procedurally in the browser.

## Run it

```bash
npm install
npm run dev
```

Open the printed local URL. For a production bundle:

```bash
npm run build
npm run preview
```

## How to play

- **WASD / arrows** — move. **Shift** — sprint. **Space** — jump.
- **E** — interact. Job stops require **holding E**.
- **F** — strike gangsters.
- **J** — gig board / 11 careers. **B** — build at an owned lot.
- **I** — pack, resources, and crafting. **M** — town map and districts.
- **G** — garage. **C** — avatar style. **Esc** — close a panel.
- Drag the mouse to orbit the camera and use the wheel to zoom.
- On phones and tablets, use the left joystick, the **E / F / ↑** touch buttons, and the bottom action bar. Job stops use a press-and-hold on **E**.

## What is in the city

- Rustmarket, Neon Row, The Foundry, and The Undercut — four claimable districts with public-works projects, passive production, and fast travel.
- Eleven work paths: ten careers plus the Fixer gang route. Every shift is a multi-stop job with real movement, hold-to-work timing, pay, XP, ranks, and perks.
- A 10×10 build grid at every owned lot: floors, walls, furniture, storage, workbenches, beds, paint, rotate, and erase.
- AI citizens who can be invited into the shelter, assigned jobs, and set to produce resources every city cycle.
- A purchasable wreck, repair kits, and live Need for Speed-style paint, rims, underglow, decals, spoilers, and headlights.
- Full avatar customization with illustrated portraits, plus survival needs, food, clinics, crafting, gang heat, combat, death, and respawn.
- LocalStorage save/resume, responsive desktop and touch layouts, and procedural WebAudio.

## Save data

Progress is stored locally under `underneath3120_save_v1`. The title screen changes **PLAY** to **CONTINUE** when a run exists. Clear the site's local storage to start over.
